# Return Processing Policy (v1)

## 1. Purpose and scope

This policy describes how a returned item moves from the customer back to our warehouse
and how it is inspected. A refund depends on the return reaching the right stage, as set
out in the Refund Policy.

## 2. Return stages

Every return passes through these stages in order:

- Requested: the customer has asked to return the item.
- In transit: the item is on its way to our warehouse.
- Received: the item has arrived at our warehouse.

A return can also be cancelled, for example if the customer decides to keep the item. A
cancelled return is treated as if no return had been requested.

## 3. Requesting a return

A return is requested on a delivered order. The date of the request is recorded, and that
date is used to check the return window in the Refund Policy. Only one active return is
considered for an order at a time: the most recent return that has not been cancelled.

## 4. Inspection

Every received item is inspected before any refund. Inspection has three outcomes:

- Pending: the item has not been inspected yet.
- Passed: the item was returned complete and in the condition expected.
- Failed: the item is missing parts, has damage caused after delivery, or is not the item
  that was sold.

A refund is not possible while inspection is pending or after inspection has failed.

## 5. What customers are told

Customers are told the current stage of their return and the inspection outcome once it is
known. They are not promised a refund until every condition of the Refund Policy is met
and a reviewer has approved it.
